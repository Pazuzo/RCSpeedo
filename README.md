# RC Speedometer - Complete GPS Speedometer for RC Cars

## What makes this different from other speedometer projects?

- ✅ **External GPS** (Flyfish M10) - не зависи от телефона  
- ✅ **ESP32 Access Point** - не ти трябва домашен рутер  
- ✅ **Cyberpunk UI** - Jetpack Compose, анимиран, графика  
- ✅ **0-60 km/h, 0-100 km/h, MAX speed, Distance**  
- ✅ **WebSocket** - двоичен 17-байтов протокол (не BLE)  
- ✅ **Ready-to-install APK** - не е нужна компилация  
- ✅ **MIT License** - свободно за ползване  

## Hardware needed
- XIAO ESP32S3+  
- Flyfish M10 GPS  
- 30 AWG silicone wires  

## Quick start
1. Flash ESP32 with provided firmware  
2. Install APK on Android  
3. Connect to WiFi `RCSpeedo`  
4. Start driving!
